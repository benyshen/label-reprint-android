## 2. 三个必须处理的点（为什么不直接缩一张图）

**① 黑底要抠成透明。** 自适应图标的前景层是透明图层，系统会按壁纸和遮罩重新合成。留一块死黑，在浅色壁纸上就是一块突兀的黑方块。

抠图不是"把黑像素删掉"这么粗暴：源图是**在纯黑上合成**的，满足 `P = C × a`（预乘 alpha），于是

```
a = max(R,G,B) / 255        反解：C = P / a
```

这样抗锯齿边缘得到自然的半透明过渡，颜色也不会被"拉黑"（直接删黑会把绿色相机的边缘啃掉一圈）。
源图底色其实是 `(8,6,8)` 这种近黑噪声，`a < 0.06` 的像素直接归零，否则缩到 48px 会蒙一层灰。

**② 主体必须落在安全区。** 108dp 画布只有中间 **72dp（66.7%）** 保证不被 launcher 的圆形/水滴形/方形遮罩切掉。
原图主体本身贴边（相机偏左上、袋子偏右下），直接铺满会被圆边啃掉。所以按 72/108 缩放后居中，四周留黑。
预览图 `shots/icon_preview.png` 是模拟圆形遮罩的结果：相机和袋子都完整，条形码在圆内。

**③ 背景色与 App 主题保持同一个黑**（`#000000`，和 `Theme.LabelReprint` 的 `windowBackground` 一致），
不然会出现"图标一块黑、点进去另一种黑"。

顺带做了 **monochrome 层**（Android 13+ 主题图标）：把前景的 alpha 当白色实心轮廓，系统开"主题图标"时会自动染色。
不做这一层也不会错，只是开主题图标时本 App 会保持彩色、和系统风格不统一。

## 3. 验证

- 已发布到桌面实测（`shots/v14_drawer1.png`、`v14_icon_zoom.png`）：应用抽屉里「标签复刻」显示为黑底 + 绿色相机 + 黄色标签袋，
  四条边都没被圆角遮罩切到
- 小尺寸 48px 预览（`shots/icon_preview_48.png`）：能认出"相机拍带条码的标签"，但**条形码的细线在 48px 下会糊成灰白纹理**——
  这是这类细节的固有上限，不是抠图或缩放的问题。真要小尺寸清晰，得单独画一版极简图标（少一根相机轮廓、条码只留 3~4 根粗线），
  本轮没做
- 覆盖安装：`adb install -r` 成功（同一个 `release.keystore`，V1.3 → V1.4 无需卸载），`versionName=1.4`
- 回归 `python tools/regress.py`：**失败 0**（demo 5 / ZPL 校验 9 / 常量自检 12）——图标改动不碰流水线，数字与 V1.3 一致
