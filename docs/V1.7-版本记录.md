## 1. V1.6 的一个致命 bug（V1.7 必须装的原因）

V1.6 装上新机（TC201 / Android 15）**一启动就闪退**，日志：

```
FATAL EXCEPTION: main
Process: com.tiaomabang.labelreprint
java.lang.RuntimeException: Unable to instantiate activity ... MainActivity
Caused by: NullPointerException: Attempt to invoke virtual method
  'android.content.Context android.content.Context.getApplicationContext()' on a null object reference
    at com.tiaomabang.labelreprint.MainActivity.<init>(MainActivity.kt:146)
```

根因：为了把 Context 交给新网关写成了字段初始化

```kotlin
private val printer = ZebraGateway(applicationContext)   // ← 崩在这里
```

**Activity 的字段初始化发生在构造函数里，那时 Context 还没 attach**，`applicationContext` 是 null。
它不会在编译期报错，只有装到机器上一跑才炸 —— 这也是"必须装机验证"的最好例子。

修法：`by lazy`，第一次真正用到时才取 Context。

```kotlin
private val printer by lazy { ZebraGateway(applicationContext) }
```

> `out/label-reprint-V1.6-release.apk` 已删除，别再用它装机。

## 2. 打印机设置改成底部标签页

上一版是"结果页窄栏 → 点打印机 → 二级页"，用户要求改成**底部标签栏**：

```
┌──────────────────────────────┐
│         （页面内容）          │
├──────────────────────────────┤
│   📷 识别    │   🖨 打印机     │  ← Scaffold 的 bottomBar
└──────────────────────────────┘
```

- 用 M3 `Scaffold(bottomBar = NavigationBar)`，两个 `NavigationBarItem`：**识别 / 打印机**。
- **打印机 tab 的图标颜色 = 链路档位**（绿=已连接 / 蓝=连接中 / 红=失败 / 灰=未连接）。
  这样在识别页也能一眼看出打印机连没连上，不用切过去确认。
- 二级页时期的 `printerPage` 状态和 `BackHandler` 一并删掉：标签页没有"返回"概念，
  物理返回键现在直接退出 App（符合系统惯例），不会再出现"按返回以为能回到上一页"。
- 结果页那条窄栏保留（`● 已连接 [SPP] ZR668 · 就绪  [打印机]`），点它等于切到打印机 tab。
- 内容安全区改由 Scaffold 统一给（`padding(pad)`），所以 **`ResultPane` 里的
  `safeDrawingPadding()` 删掉了** —— 留着会与 bottomBar 的导航栏内边距叠成双份。

## 3. 真机验证（TC201L / Android 15 / 三键导航）

| 项 | 结果 |
|---|---|
| 启动 | 不再闪退，`INTENT >>>` / `CAMERA >>> bound｜preview=1600x1200 capture=4096x3072` |
| 底部标签栏 | 两项正常，选中态是荧光绿胶囊；内容与导航栏不重叠 |
| 打印机 tab | 状态卡「已连接 SPP 刚刚 / ZR668 · XXZKJ184301333 / AC:3F:A4:F2:56:2F / 就绪」，两栏设备、扫描按钮、自动连接开关、测试页、校准都在，滚到底不遮挡 |
| 经典蓝牙连接 | `已建立连接：BluetoothConnection` → `connected: ZR668 @ BT:AC:3F:A4:F2:56:2F (linkOs=true)` → `状态=就绪` |
| 自动连接 | 重启 App 后 `PRINT >>> 自动连接上次的打印机 BT:AC:3F:A4:F2:56:2F` → 3s 内连上 |
| 状态轮询 | `PRINT >>> 状态刷新：就绪（alive=true）`，5s 一次 |
| **BLE 扫描** | `BLESCAN >>> 结束，共 20 台`，其中 `XXZKJ184301333@AC:3F:A4:F2:56:2F(zebra=true)`（SDK 认出、-34dBm），其余 19 台为附近蓝牙音箱/家电等，标「未识别」 |
| 测试页 | `PRINT >>> 打印测试页（经典蓝牙（SPP））` → `发往 ...，ZPL 174 字节` → `成功 525 ms` |
| 回归 | `python tools/regress.py` 失败 0 |

**未验证**：BLE 打印机实机出纸（手边只有 ZR668，走的是经典蓝牙）；不过 ZR668 在 BLE 扫描里
被 SDK 认成 Zebra 打印机，说明 BLE 发现这一段在本机可用。
