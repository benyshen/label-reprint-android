# V1.9 版本记录（2026-10-20）

**一句话：把 AI Data Capture SDK 从 4.1.0 换回 4.0.6，DL 条码引擎在 TC201 上复活。**
条码模型仍是 `barcode-decoder-5.0.4.aar`（没换）。

---

## 1. 根因（V1.8 只查到"被拒"，这一版找到"为什么"）

V1.8 查出 4.1.0 的 `AIVisionSDK.<init>` 在 TC201L 上抛
`UnsupportedOperationException: AI Vision SDK is not supported`，且 Zebra 自家 App 也崩。
按用户指出的版本组合换成 **AI-Data-Capture-SDK-4.0.6.aar**（模型不变）后：

```
ZEBRA settings: detectorSetting=true enableAI=false enableLoc=true dims=1280x1280
ZEBRA decoder ready in 3859ms
ZEBRA LOCALIZE -> [QR Code ...] | [Code 128 ...]
ZEBRA DECODE_ALL -> [Code 128 'ABcD1234' ...]
```

即 **4.1.0 里的机型门控在 4.0.6 上不存在**（4.0.6 不限制机型）。这不是配置问题，
是 SDK 版本本身的差异，所以只能锁版本。

## 2. 改动

- `android-app/app/libs/AI-Data-Capture-SDK-4.0.6.aar`（从 `E:\workspace\models` 拷入，66,568,156 B）
- `AI-Data-Capture-SDK-4.1.0.aar` 保留原件 + `.bak`，只把 `build.gradle.kts` 的依赖指向 4.0.6
- `barcode-decoder-5.0.4.aar` 未动（DL 模型还是原来那个）
- `versionCode 10 / versionName "1.9"`

> 依赖写的是 `files("libs/AI-Data-Capture-SDK-4.0.6.aar")` —— **别再手滑写回 4.1.0**，
> 那条路在这台机器上是死的。

## 3. 真机验证（TC201L / QCS6690 / Android 15）

**初始化和能力**（`--es zprobe init`）：

| 项 | 结果 |
|---|---|
| init | `ZEBRA decoder ready in 3859ms`（首次解模型包） |
| PROCESS | QR Code / Code 128 都出，带真包围盒 |
| LOCALIZE | 5 个候选框 → 2 个符号（原图两处） |
| 耗时 | 首张 1780ms（含 init），之后每张 ~650ms |

**三张样例（`--es all 1`，hybrid）**：

| 样图 | 引擎 | 要素 |
|---|---|---|
| label_sample_1 | `zebra(on)=2 zxing=2 合并=2` | Code 128 `ABC123` + QR |
| label_sample_2 | `zebra(on)=2 zxing=2 合并=2` | Code 128 `ABC123` + QR `RA` |
| label_sample_3 | `zebra(on)=2 zxing=2 合并=2` | Code 128 `ABC123` + QR `RA` |

**用户真机照片（`拍照.png` 2449×3265）—— 这就是"条码丢失"的那类图**：

| | V1.8（zxing only） | V1.9（hybrid，DL 回来了） |
|---|---|---|
| 引擎 | `zebra(off)=0 zxing=1 合并=1` | `zebra(on)=4 zxing=2 合并=4` |
| 结果 | 只有 1 个二维码 | **2× QR + 2× Code 128**（另加 OCR 文字，共 8 要素） |

→ 同一张照片，之前只有二维码、**一维码全丢**；现在一维码出来了。用户说的"条码识别功能丢失"
就是这个：DL 一停，一维码在那张图上 zxing 解不出来。

## 5. 遗留

1. `enableAI=false`（AI Barcode Decode 那档没开）：4.0.6 的默认设置里没打开，
   目前靠 localize + decode_all 已经能解 QR/Code128。要不要开 AI 档，等实际标签再说。
2. V1.8 加的 zxing 多轮补救保留 —— 现在是"DL 优先 + zxing 兜底 + 补救轮"，
   DL 解不出的一维码（超低分辨率）还有第二道网。
3. TC73 上同样用 4.0.6，行为一致（未重测；它是 4.1.0 也能跑的机型）。
