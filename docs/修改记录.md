### 1.2 装机注意：这次必须**先卸载**旧版

签名从 debug 换成正式密钥，`adb install -r` 会报 `INSTALL_FAILED_UPDATE_INCOMPATIBLE`。卸载会一并删掉
`/sdcard/Android/data/com.tiaomabang.labelreprint/files/shots/` 里的历史照片备份（本次实测清了 3 张），需要的话先拷出来：

```bash
adb pull /sdcard/Android/data/com.tiaomabang.labelreprint/files/shots ./shots-backup
adb uninstall com.tiaomabang.labelreprint
adb install out/label-reprint-V1.3-release.apk
```

**以后的版本都用同一个 `release.keystore` 签名，可以原地 `install -r` 升级。**

## 二、构建命令

```bash
cd android-app
./gradlew assembleRelease          # -> app/build/outputs/apk/release/app-release.apk
```

`versionName` 唯一真源是 `app/build.gradle.kts`；界面上读 `PackageManager`，不写死。

`isMinifyEnabled = false`：本轮不混淆——Zebra SDK 与 AI-Data-Capture 大量走反射/回调，
混淆要逐个补 keep 规则，风险高于收益（当前收益只有几十 MB 的 dex）。
APK 体积的大头是模型（153 MB）与高通 SNPE/ORT 原生库（约 150 MB），不是能靠混淆省掉的部分。
