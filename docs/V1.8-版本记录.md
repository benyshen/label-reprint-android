# V1.8 版本记录（2026-10-20）

**主题：查"条码识别丢了"，并给一维码补精度。** 结论是：**代码没丢**，是这台 TC201 上
Zebra DL 引擎压根起不来 —— 厂商 SDK 直接拒绝；一维码只剩 zxing 一条路，所以加固 zxing。

---

## 1. 现象排查：为什么觉得"条码识别没了"

在 TC201 上用 `--es zprobe init` 拉日志：

```
E LABELREPRINT: ZEBRA init failed: UnsupportedOperationException: AI Vision SDK is not supported
E   at com.zebra.ai.vision.detector.AIVisionSDK.<init>(AIVisionSDK.java:195)
```

同一台机器上跑 **Zebra 自家的 AI Barcode Finder**（`com.zebra.ai.barcodefinder`）也报同一句：

```
E EntityTrackerCoordinator: java.lang.UnsupportedOperationException: AI Vision SDK is not supported
    #17 ... com.zebra.ai.vision.detector.AIVisionSDK.<init>(AIVisionSDK.java:0)
```

→ **不是我们的代码坏了，是这台设备/固件上 AI Data Capture SDK 被拒**：
- 机型 TC201L，SoC **QCS6690**，Android 15，固件 `15-19-16.00-VN-U00-STD-ERS-04`；
- 设备上装了 `com.zebra.ai.barcodefinder 1.3.7`、`com.zebra.ai_multibarcodes_capture.dev 2.1.0`，
  但 SDK 仍然说 "not supported"（Zebra 的说法是 Q-6690 需 FP2 及以上，具体看支持门户）；
- 我们在 TC73 上跑出来的 `ZEBRA decoder ready in 2983ms` 在这台机器上再也拿不到。

所以实际状态是：**微信码/一维码都还在识别（zxing-cpp 在跑），只是少了一半引擎**。
在 TC201 上之前一直是"DL 管二维码、zxing 管一维码"的混合策略，现在等于只剩 zxing。

## 2. 加固 zxing（真正的改动）

`barcode/BarcodeEngine.kt` 的 `ZxingCppEngine` 从"一次全图扫描"改成**按需多轮**：

| 轮 | 触发条件 | 设置 |
|---|---|---|
| base | 总是跑 | 全码制、tryHarder、tryRotate、tryDownscale |
| 1d | base 没解出一维码 | 只留一维码码制白名单 + tryDenoise |
| 1d-inv | 仍没有 | 同上 + tryInvert（银底/黑底标签） |
| 1d-2x | 仍没有 | 整图放大 2 倍，`minLineCount=1`（矮条码不再被滤掉） |
| 1d-2x-hist | 仍没有 | 同上 + `GLOBAL_HISTOGRAM` 二值化（光一半亮一半暗时更稳） |

- 坐标统一按放大倍数除回原图（`px`/`quad` 都除 `scale`），否则要素会被排到标签外面。
- 每轮结果并进同一张表，键是"码制+内容"，留框大的那个。
- 每轮耗时与命中数打进日志：`ZXPASS >>> base=2/2 8ms 1d=0/0 12ms 合计=20ms`，
  以后一维码再出问题，一看便知卡在哪一轮。

实测（TC201，V1.8）：

| 样图 | 结果 |
|---|---|
| `label_sample_2.png`（Code128 + QR） | `base=2/2 8ms`，Code 128 `ABC123` + QR `RA` |
| `photo_m2p5px_b0p8_n3p0.png`（每模块 2.5px 的难图） | `base=1/1 77ms`，Code 128 `ABC123` |
| 用户真机照片 `20261020_210308.jpg` | QR `ABCD1234` 命中，OCR 出 `仓库标签` 等 |

补救轮在样例上没被触发（base 就解出来了），所以它的作用是**兜底**，不是每张都付这份时间。

## 3. 界面：把"为什么只剩 zxing"说出来

结果页 **警告区**现在会多一行（只在这台机器 DL 不可用时出现）：

```
· 警告：条码库：UnsupportedOperationException: AI Vision SDK is not supported，仅 zxing 识别
```

日志里 `HYBRID >>>` 也会带上 `DL 不可用：...`。以前这条信息只写进 logcat，
界面上完全安静 —— 用户只会觉得"识别功能没了"。

   后者要再看是不是标签检测/取景框过滤把整张图丢了。

   或等 TC201 的固件升到 AI Suite 支持的版本；代码层面不需要改。
3. 若用户手上有一维码标签，拍一张（会自动存 `files/shots/`），我可以直接读日志看卡在哪一轮。
